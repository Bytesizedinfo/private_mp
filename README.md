# Spend & Save

A simple budgeting app for your phone: see all your money, what you can spend today, this week or this month, and what to set aside for your goals.

**Your data stays on your phone.** Nothing you log is sent anywhere or stored in this repository. Use Plan → More → Download a backup now and then.

## Install it
- **iPhone:** open the site in Safari, tap Share, then **Add to Home Screen**.
- **Android:** open the site in Chrome, tap the menu, then **Install app**.

## Moving your data in
On the first screen, tap **Restore from a backup** and pick a Spend & Save backup file (`spend-save-backup-….json`).
